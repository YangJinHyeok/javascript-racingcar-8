# javascript-racingcar-precourse

## 구현할 기능 목록  

---

## 자동차 이름 입력 기능  
- 사용자가 경주할 자동차 이름을 쉼표(`,`)로 구분해 입력한다.  

---

## 시도 횟수 입력 기능  
- 몇 번의 시도를 할지 숫자로 입력받는다.  

---

## 자동차 객체 생성 기능  
- 각 이름으로 자동차 객체를 생성한다.  
- 자동차는 이름(`name`)과 현재 위치(`position`) 정보를 가진다.  

---

## 자동차 전진 기능  
- `Random.pickNumberInRange(0, 9)`를 사용해 난수를 생성한다.  
- 생성된 숫자가 4 이상이면 자동차가 한 칸 전진한다.  

---

## 경주 진행 기능  
- 입력받은 시도 횟수만큼 모든 자동차가 전진 여부를 반복 수행한다.  

---

## 결과 출력 기능  
- 각 시도마다 모든 자동차의 전진 결과를 출력한다.
- 우승자가 여러 명일 경우 쉼표(`,`)로 구분하여 출력한다.
  
---

## 우승자 판별 기능  
- 가장 멀리 이동한 자동차를 우승자로 선정한다. 


---

## 예외 처리 기능  
- 이름이 1자 미만이거나 5자를 초과할 경우 예외를 발생시킨다.
- 중복된 자동차 이름이 있을 경우 예외를 발생시킨다.  
- 시도 횟수가 유효하지 않을 경우 예외를 발생시킨다.  
- 모든 예외는 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.
